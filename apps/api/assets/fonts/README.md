# Bundled fonts

These fonts are open-source Google Fonts, distributed under the SIL Open Font
License 1.1. They are bundled so FFmpeg/libass renders the same family the UI
offers instead of falling back to a system font.

| File | Family | Source |
| --- | --- | --- |
| `Anton-Regular.ttf` | Anton | https://github.com/google/fonts/tree/main/ofl/anton |
| `Oswald.ttf` | Oswald (variable) | https://github.com/google/fonts/tree/main/ofl/oswald |
| `Inter.ttf` | Inter (variable) | https://github.com/google/fonts/tree/main/ofl/inter |
| `Montserrat.ttf` | Montserrat (variable) | https://github.com/google/fonts/tree/main/ofl/montserrat |
| `PinyonScript-Regular.ttf` | Pinyon Script | https://github.com/google/fonts/tree/main/ofl/pinyonscript |
| `EBGaramond.ttf` | EB Garamond (variable) | https://github.com/google/fonts/tree/main/ofl/ebgaramond |
| `BebasNeue-Regular.ttf` | Bebas Neue | https://github.com/google/fonts/tree/main/ofl/bebasneue |
| `ArchivoBlack-Regular.ttf` | Archivo Black | https://github.com/google/fonts/tree/main/ofl/archivoblack |
